# LMPO-cycle-life-prediction-model-from-the-formation-cycle

This repository presents an end-to-end machine learning pipeline designed for early battery cycle-life prediction and optimal formation protocol screening using formation-cycle electrochemical data. The workflow encompasses automated raw data preprocessing and normalization for time-series voltage and current profiles, followed by the training of neural network architectures to predict long-term capacity retention and degradation behavior. To ensure model interpretability, the framework integrates Grad-CAM and SHAP analyses, enabling the extraction of critical spatial and temporal features associated with degradation mechanisms such as interfacial reactions and high-voltage oxidation. Finally, the pipeline provides a protocol screening module that utilizes trained inference models on preprocessed formation datasets to rapidly evaluate unseen formation strategies and identify protocols optimized for extended cell longevity.
